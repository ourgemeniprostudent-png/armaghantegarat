# ارمغان تجارت وطن — نسخه قابل ادامه در Codex Cloud

نسخه قالب: **۱.۱۲.۱**؛ بر پایه صفحه اصلی تاییدشده ۱.۷.۰. این مخزن آخرین طراحی تاییدشده پروژه را شامل می‌شود؛ فایل ZIP قدیمی مبنای آن نیست.

نسخه ۱.۱۲.۱ واژه دورخط «تجارت» در جمله بزرگ صفحه اصلی را طبق درخواست مالک، به‌عنوان استثنا طلایی می‌کند.

نسخه ۱.۱۲.۰ ترکیب‌بندی صفحات داخلی را بازسازی می‌کند: صحنه حجمی طلایی و پس‌زمینه دریایی تماس، روایت سرتاسری درباره و همکاری، فرم روشن مرحله‌ای و چیدمان تحریریه‌ای مجله. پالت پایه آبی برند، مشکی، طلایی و زرشکی است؛ سبز رابط حذف شده است. جزئیات در [گزارش نسخه ۱.۱۲](docs/RELEASE-1.12-fa.md).

نسخه ۱.۱۱.۰ معرفی تماس را با تصویر بندر و قهوه، تماس مستقیم در نمای اول و فرم روشن دو ستونی تکمیل می‌کند. رنگ زمینه درباره ما، تماس و مجله، نمایش معرفی تماس و صحنه دریایی از تنظیمات قالب کنترل می‌شوند.

جهت فلش مورب مشترک را در تمام سایت به بالا و چپ یکسان می‌کند؛ لینک‌ها، نشان‌های بصری و حالت بدون جاوااسکریپت همین جهت را دارند.

نسخه ۱.۱۰.۴ شروع صفحات داخلی را منظم می‌کند: مسیر صفحه در یک ردیف زیر هدر، فاصله کوتاه‌تر تا عنوان و برچسب معرفی نزدیک تیتر. مسیرهای دسته، صفحه فرزند و مقاله واقعی‌اند؛ نمایش مسیر و متن مشترک آن از تنظیمات قالب و ویرایش هویت مدیریت می‌شوند.

نسخه ۱.۱۰.۳ زرشکی را در عنوان‌های بزرگ دورخط هم به کار می‌برد؛ رنگ و شدت آن به همان تنظیمات رنگ سوم وصل است و فرم توخالی و موشن حفظ شده‌اند.

نسخه ۱.۱۰.۲ صفحه انتظار لوگو را حذف می‌کند و ویدیو اصلی را بدون اجبار دانلود کامل به پلیر بومی مرورگر می‌دهد. بایت‌های هر دو ویدیو محفوظ‌اند؛ سایت پیش از آماده‌شدن ویدیو قابل استفاده است. بررسی اختصاصی: `python3 scripts/check-video.py`.

نسخه ۱.۱۰.۱ آزمایش زرشکی سلطنتی محدود در جزئیات مشکی و طلایی است. نمایش، رنگ و شدت آن از تنظیمات قالب قابل تغییر است؛ خاموش‌کردن آن ظاهر پیشین را برمی‌گرداند.

سایت یک وردپرس فارسی و راست‌به‌چپ با مولتی‌سایت است. قالب اختصاصی، افزونه مدیریت محصولات و درخواست‌ها، فونت‌ها، تصاویر و ویدیو فعلی در مخزن هستند. محتوای عمومی فعلی (۱۳ صفحه و ۸ نوشته) و تنظیمات نمایشی در یک فایل JSON منتقل شده‌اند. هیچ دیتابیس اصلی، کاربر اصلی، رمز یا درخواست مشتری در مخزن قرار ندارد.

## راه‌اندازی

در محیط لینوکسی Codex Cloud:

```bash
bash scripts/cloud-setup.sh
bash scripts/start.sh
python3 scripts/smoke.py
```

`cloud-setup.sh` در صورت نبود PHP/SQLite، بسته‌های موردنیاز را با apt نصب می‌کند. اگر اجازه نصب یا شبکه فراهم نیست، همان وابستگی‌ها باید در مرحله آماده‌سازی محیط نصب شوند. وردپرس، WP-CLI و SQLite integration همراه مخزن هستند و نصب خود سایت به دانلود اینترنتی وابسته نیست.

در محیطی که PHP 8.1 یا بالاتر، PDO SQLite و GD دارد:

```bash
bash scripts/setup.sh
bash scripts/start.sh
```

پیش‌فرض توسعه `http://127.0.0.1:8788/` است. پیش از **اولین** راه‌اندازی، برای استفاده از پورت دیگر:

```bash
ARMAGHAN_SITE_URL=http://127.0.0.1:8799 bash scripts/setup.sh
bash scripts/start.sh
```

برای انتخاب باینری PHP از `ARMAGHAN_PHP_BIN` استفاده کنید. آدرس اتصال سرویس به‌صورت پیش‌فرض `127.0.0.1` است؛ `ARMAGHAN_BIND_ADDRESS` فقط در صورت نیاز واقعی محیط برای فوروارد کردن پورت قابل تنظیم است.

در ابزار اجرایی که پردازش پس‌زمینه را پس از پایان دستور متوقف می‌کند، سرویس را با `bash scripts/start.sh --foreground` در یک نشست دستور طولانی اجرا کنید و بررسی‌ها را از دستور دیگری انجام دهید.

نام کاربری و رمز تازه توسعه در `.runtime/access.txt` ذخیره می‌شوند. این فایل و کل `.runtime/` در Git نادیده گرفته می‌شوند. هیچ رمز ثابت عمومی نداریم. برای توقف سرویس همین پروژه:

```bash
bash scripts/stop.sh
```

اجرای دوباره setup فایل‌های منبع را وصل می‌کند و دیتابیس موجود را پاک یا دوباره seed نمی‌کند. برای عوض کردن دامنه یک وردپرس موجود، مهاجرت آگاهانه مولتی‌سایت لازم است؛ setup از بازنشانی خودکار داده‌ها خودداری می‌کند.

فایل‌های بزرگ ویدیو و بسته وردپرس در `payload/` به قطعات ۱۶ مگابایتی ذخیره شده‌اند تا انتقال پایدار بماند. setup قبل از راه‌اندازی آن‌ها را بدون تغییر کیفیت یا تبدیل فرمت بازسازی می‌کند و SHA-256 تمام قطعات و فایل نهایی را بررسی می‌کند.

## ساختار

- `theme/vatan-authority/` — قالب فعلی و تمام رسانه موردنیاز
- `plugin/vatan-core/` — محصولات، رسانه، ثبت پایدار و پیگیری درخواست‌ها
- `content/public-site.json` — فقط محتوای عمومی و تنظیمات نمایشی منتقل‌شده
- `payload/` — قطعات فایل‌های بزرگ با فهرست هش و بازسازی دقیق
- `vendor/` — نسخه‌های فعلی وردپرس، WP-CLI، SQLite integration و ترجمه فارسی؛ همراه مجوزهای اصلی
- `scripts/` — نصب، اجرا، توقف و بررسی سلامت
- `.agents/skills/start-armaghan/` — مهارت شروع سرویس در محیط آماده
- `docs/HANDOFF-fa.md` — وضعیت طراحی و تصمیم‌های ادامه کار
- `.runtime/` — داده توسعه تولیدشده؛ خارج از Git

## استفاده در Codex Cloud

این مخزن را برای محیط `ourgemeniprostudent-png/armaghantegarat` انتخاب کنید. برای آماده‌سازی از Codex بخواهید `bash scripts/cloud-setup.sh` را اجرا کند و سپس سرویس و smoke check را آزمایش کند. Install script باید نصب را آماده کند؛ Start skill می‌تواند مهارت `start-armaghan` داخل همین مخزن باشد. پس از موفق بودن بررسی‌های محیط، Publish را بزنید.

وجود کد در GitHub به معنی انتشار یک وب‌سایت عمومی یا فعال شدن خودکار یک ماشین ابری نیست. پیش‌نمایش از خارج محیط به قابلیت فوروارد کردن پورت یا هاست تست جدا نیاز دارد. این کپی برای توسعه است؛ SQLite و سرور داخلی PHP را بدون آماده‌سازی جدا برای سایت نهایی عمومی استفاده نکنید.

## محتوای انتقال و مجوزها

کدها و رسانه‌های همین پروژه بنا به درخواست صاحب پروژه منتقل شده‌اند. وردپرس و افزونه SQLite مجوزهای اصلی خود را در فایل‌های vendor حفظ کرده‌اند؛ باینری WP-CLI نیز نسخه رسمی موجود در پروژه است. فونت و رسانه‌های پروژه برای ادامه همین سایت نگهداری شده‌اند؛ این مخزن ادعای مجوز بازتوزیع عمومی مستقل برای دارایی‌های برند نمی‌کند.

راهنمای ویرایش سکشن‌ها و صفحات تکمیل‌شده در [docs/EDITING-fa.md](docs/EDITING-fa.md) است. پیش‌نمایش عمومی تنها خروجی دیدنی است؛ ثبت واقعی فرم و مدیریت محتوا در وردپرس انجام می‌شوند.

## طراحی صفحات داخلی ۱.۹

صفحات داخلی، پرونده‌های محصول و مجله با روایت‌های تصویری، دیاگرام مسیر، تایپوگرافی بزرگ و موشن وابسته به اسکرول بازطراحی شدند. مجله و متن سه مقاله زمینه روشن دارند. طراحی صفحه اصلی، ویدیوهای اصلی و معماری وردپرس محفوظ‌اند. متن‌های تازه بر اطلاعات عمومی منتقل‌شده و راهنمای عملی تنظیم شده‌اند؛ منابع اصلی پوشه reference در این مخزن موجود نیستند.

متن اصلی سه مقاله در content/public-site.json و سکشن‌ها در plugin/vatan-core/content/sections-fa.json قرار دارند. نصب تازه آن‌ها را وارد می‌کند؛ نصب موجود را reset نکنید. تغییر محتوای مقاله‌های موجود باید با حفظ بازبینی‌ها از ویرایشگر وردپرس انجام شود. پیش‌نمایش فعال: https://ourgemeniprostudent-png.github.io/armaghantegarat/

طراحی تاییدشده مشکی و طلایی حفظ شده است. مرکز «تنظیمات قالب ارمغان تجارت وطن» اطلاعات دفتر، کنترل قابلیت‌ها و دسترسی مستقیم به ویرایش صفحات، منوها و فوتر را فراهم می‌کند. جستجو و موضوعات مجله، راهنماهای پنج گروه، گالری و فیلتر مشخصات واقعی محصولات، رسانه با متن و زمان‌بندی، فرم کوتاه تماس و شمارش اختیاری رویدادها اضافه شده‌اند.

